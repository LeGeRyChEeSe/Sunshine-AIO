# Story 2.2: Création du composant Sun (Soleil)

## User Story

As a user,
I want to see the sun as the central element representing core tools,
So that I understand which tools are the core of the system.

## Acceptance Criteria

**Given** The 3D scene is initialized
**When** The scene renders
**Then** A sun with orange/yellow glow effects is displayed at the center
**And** The sun has a pulsing animation effect

**Given** The sun is rendered
**When** The core tools (Sunshine/Apollo, VDD, Playnite) are installed
**Then** Visual indicators show the core tools status on the sun
