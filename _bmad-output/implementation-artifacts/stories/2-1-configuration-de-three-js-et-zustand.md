# Story 2.1: Configuration de Three.js et Zustand

## User Story

As a developer,
I want to set up Three.js and Zustand state management,
So that I can build the 3D solar system interface.

## Acceptance Criteria

**Given** The Electron project is initialized
**When** I install Three.js and Zustand dependencies
**Then** Three.js renders in the application window
**And** Zustand stores can manage application state

**Given** Three.js is configured
**When** The application renders a basic 3D scene
**Then** A canvas element displays the 3D content
**And** The frame rate is monitored and logged
